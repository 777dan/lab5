# Сайт "Краєвиди Слобожанщини"

## Загальні відомості про ресурс
"Краєвиди Слобожанщини" - це інформаційно-пізнавальний вебсайт, присвячений природним перлинам, заповідникам та визначним ландшафтним місцям Слобідської України. Ресурс створено для популяризації туризму, ознайомлення відвідувачів з красивою природою краю та допомоги у плануванні вихідного дня за містом.

## Цільова аудиторія
Сайт призначений для:
* Туристів, які шукають цікаві місця для подорожей Україною
* Мешканців Слобожанщини, які бажають краще дослідити природу рідного регіону
* Любителів активного відпочинку, екотуризму та фотографування

## Функціональні вимоги
Ресурс надає користувачам такі можливості:
* Перегляд інформації про туристичний потенціал Слобожанщини на головній сторінці
* Ознайомлення з локаціями
* Перегляд описів та фотографій кожного місця
* Навігація між сторінками сайту (меню навігації)
* Перегляд географічного розташування цих місць

## Структура сайту
Сайт є багатосторінковим і складається з 8 HTML-сторінок:
* index.html - Головна сторінка (загальний опис регіону та його туристичний потенціал)
* slobozhanskyi.html - Національний природний парк «Слобожанський»
* dvorichanskyi.html - Дворічанський національний природний парк
* kremenets.html - Гора Кременець
* kytsivska.html - Кицівська пустеля
* krasnokutsk.html - Краснокутський дендропарк
* gomilshanski.html - Національний природний парк «Гомільшанські ліси»
* solone-ozero.html - Солоне озеро (Антонівка)

## Вимоги до дизайну
* Колірна гама: природна зелена палітра (відтінки лісової зелені) у поєднанні зі світлим нейтральним фоном для комфортного читання тексту та темним кольором для основного шрифту.
* Типографіка: шрифт для заголовків - Montserrat, для основного тексту - Open Sans.
* Оформлення: інтерфейс з акцентом на візуальні матеріали (фотографії природи) та інформаційні блоки.

## Технічні вимоги
* Використані технології: HTML5, CSS3, Bootstrap 5.
* Адаптивність: коректне відображення сторінок на пристроях із різною роздільною здатністю екрана (смартфони, планшети, ноутбуки).
* Кросбраузерність: підтримка роботи сайту в сучасних браузерах (Google Chrome, Microsoft Edge, Mozilla Firefox).

## Використані зовнішні матеріали та джерела
* Текстові матеріали. Матеріали підготовлено на основі відкритих енциклопедичних та туристичних джерел (Вікіпедія, сайти національних природних парків України, туристичні портали Харківської області).
* Зображення та графіка. Фотографії локацій взято з відкритих джерел.
